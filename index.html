Cara Pasang di Head Unit Bryton:

  1. Ekstrak file .zip hasil download.
  2. Hubungkan Bryton Rider ke Komputer via kabel USB.
  3. Buka folder Bryton → tracks di dalam storage perangkat.
  4. Salin file .smy, .track, dan .tinfo ke folder tracks tersebut.
  5. Cabut aman (Eject), buka menu Follow Track / Ikuti Rute di Bryton Anda!
